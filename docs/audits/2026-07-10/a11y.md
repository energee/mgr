# WCAG 2.2 AA Static Audit — raw report (agent: ecc:a11y-architect, 2026-07-10)

Scope: data-table/, universal/entity-data-table + entity-mobile-card-list, ui/{dialog,sheet,form,input,table,button,badge,sonner,dropdown-menu,input-otp}, universal/status-badge + field-input, domain/pricing/*, domain/inventory/inventory-alerts, domain/shared/{notification-bell,chat-toggle}, staff login + portal login/OTP, sample of react-hook-form dialogs (yeast-harvest, record-cell-count, pitch-yeast, vessel-transfer, batch-cancellation, create-batch-from-shortfall).

**Credited (radix/stack handles correctly, not re-flagged):** Dialog/Sheet/AlertDialog/DropdownMenu/Select/Combobox unmodified radix wrappers — focus trap, Escape, focus return OK; all 41 DialogContent pair with DialogTitle. ui/form.tsx FormField/FormControl/FormMessage correctly wires aria-describedby + aria-invalid + role="alert" — just not always used (A11Y-3/4). Sonner Toaster renders real aria-live="polite" region. input-otp defaults autoComplete="one-time-code". data-table-sort-list and pagination well-built (correct aria-label/aria-controls/keyboard). entity-mobile-card-list wraps cards in real <Link> with sibling labeled actions button — the accessible pattern the desktop table should match.

**A11Y-1 — High — Desktop entity-list rows have no keyboard path of their own**
data-table/data-table.tsx:65-85 (TableRow cursor-pointer, no tabIndex/role; per-TableCell onClick :78-85 no onKeyDown); wired via universal/entity-data-table.tsx:260-266, :1317. WCAG 2.1.1, 4.1.2.
Every staff entity list = mouse-only row target. Keyboard path exists only via undiscoverable "…" menu View link (adapter.tsx:267).
Fix: primary column renders real <Link> (match portal orders page :83-88 and mobile card list), or drop row-click affordance.

**A11Y-2 — High — Row-actions "…" trigger has no accessible name (every entity table)**
data-table/adapter.tsx:261-265. WCAG 4.1.2, 1.1.1. Ghost Button + MoreHorizontal svg, no aria-label — unlabeled "button" app-wide.
Fix: aria-label="Row actions" (pattern in entity-mobile-card-list.tsx:417, data-table-sort-list.tsx:385,395).

**A11Y-3 — High — react-hook-form errors not associated to inputs (7+ dialogs)**
record-cell-count-dialog.tsx:150-163,168-183,189-203; pitch-yeast-dialog.tsx:389-459; yeast-harvest-dialog.tsx:228-298; vessel-transfer-dialog.tsx:388-418; batch-cancellation-dialog.tsx:248-300; create-batch-from-shortfall.tsx:220-296; settings/system/page.tsx:304-306. WCAG 3.3.1, 1.3.1, 4.1.2.
useForm+zodResolver but raw {...form.register()} on bare <Input> + hand-rolled {error && <p>} instead of repo's own FormField/FormControl/FormMessage. No id/aria-describedby/aria-invalid — ui/input.tsx:13 aria-invalid styling never activates (sighted users lose visual cue too).
Fix: swap manual blocks for Form/FormField — drop-in.

**A11Y-4 — Critical — Login and portal-login forms give no feedback on validation failure**
(auth)/login/login-form.tsx:178-186 (email), :199-207 (password); portal/(auth)/login/portal-login-form.tsx:168-181 (email). WCAG 3.3.1, 4.1.2, 4.1.3.
Manual useState + zod safeParse; bare <p class="text-destructive"> with no id/aria-describedby/aria-invalid/role="alert". Screen-reader user at the only entry point gets zero announcement — can fully block sign-in.
Fix: same as A11Y-3, or minimally add id/aria-describedby/aria-invalid/role="alert".

**A11Y-5 — Medium — Email/password inputs missing autocomplete**
login-form.tsx:178-185, 199-206; portal-login-form.tsx:168-178. WCAG 1.3.5 (AA).
Fix: autoComplete="email"/"current-password".

**A11Y-6 — Medium — Table headers never set scope (every table)**
ui/table.tsx:68-79 (TableHead → bare <th>); consumed by data-table.tsx:46-57, pricing-matrix-view.tsx:325-344 (+ tier-name row labels :356-365 use TableCell not scope="row" header), portal orders page :70-77. WCAG 1.3.1.
Fix: default scope="col" in TableHead; scope="row" option for row-label cells.

**A11Y-7 — Medium — Pricing-matrix cell buttons unlabeled for blank cells; error toast-only**
domain/pricing/price-cell.tsx:127-140 (button), :63-77 (commit), :112-123 (edit input). WCAG 4.1.2, 3.3.1.
Unset price renders "·" — unlabeled "· button" repeated with no tier/format context. Invalid commit exits edit mode with toast.error only.
Fix: aria-label = tier + format + value; stay in edit mode with inline error.

**A11Y-8 — Low — Disabled action-menu reason exposed only via title**
data-table/adapter.tsx:277-279. WCAG 4.1.2 (best practice). disabledReason passed only as HTML title.
Fix: aria-describedby to visually-hidden node, or fold into label.

**A11Y-9 — Low — StatusBadge dotOnly mode is color-only (unused, latent)**
universal/status-badge.tsx:52-53, 63-64. WCAG 1.4.1. No call site passes dotOnly (verified), but shared primitive has no safety rail.
Fix: aria-label={label} even when dotOnly (pattern: notification-bell.tsx:100-102).

**Summary:** Radix/shadcn foundation solid. Real gaps = two systemic app-layer patterns: non-keyboard-operable table rows (A11Y-1/2, every entity list) and hand-rolled forms bypassing the project's own accessible Form primitives (A11Y-3/4, including the login gate). Highest-leverage lowest-effort: A11Y-4 (login) + A11Y-2 (row-actions label). A11Y-1/3 touch more call sites but have in-repo reference implementations to copy.
