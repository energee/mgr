### Task 2: Replace relation field Select with Combobox in EntityForm

**Files:**
- Modify: `src/components/universal/entity-form.tsx` (lines ~27-33 imports, lines ~608-636 relation case)

**Context:**
- The `case "relation"` block at line 608 currently renders a `<Select>` with options from `dynamicOptions`
- Options are `{ value: string; label: string }[]` where `value` is a UUID and `label` is the display name
- The current value is a UUID string or `null`
- Non-required relation fields need a way to clear the selection (currently `_none` sentinel)

**Step 1: Add combobox imports to entity-form.tsx**

Add imports for the Combobox components at the top of `entity-form.tsx`. The exact import names depend on what Task 1 installed — read `combobox.tsx` exports first. Expected pattern:

```typescript
import {
  Combobox,
  ComboboxAnchor,
  ComboboxInput,
  ComboboxTrigger,
  ComboboxCancel,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxItem,
  ComboboxItemIndicator,
  ComboboxItemText,
} from "@/components/ui/combobox";
```

Only import what you actually use. You will NOT need: `ComboboxBadgeList`, `ComboboxBadgeItem`, `ComboboxBadgeItemDelete` (those are for multi-select), `ComboboxPortal`, `ComboboxArrow`, `ComboboxLoading`, `ComboboxGroup`, `ComboboxGroupLabel`, `ComboboxSeparator`, `ComboboxLabel`.

**Step 2: Replace the `case "relation"` block**

Replace lines 608-636 in `entity-form.tsx` with a Combobox implementation. The key mapping:

- `value` prop: The Combobox expects `value` as a `string` (or `string[]` for multi). Pass the current UUID or `""` for null.
- `onValueChange`: Receives the selected UUID string. Convert `""` to `null` for the form state.
- Options rendered as `ComboboxItem` with `value={option.value}`
- The Combobox handles search/filtering internally via `ComboboxInput`
- For non-required fields, include a clear button (`ComboboxCancel`) so users can deselect

```typescript
case "relation": {
  const options = dynamicOptions || [];
  const selectedLabel = options.find((opt) => opt.value === String(value))?.label;

  return (
    <Combobox
      value={value ? String(value) : ""}
      onValueChange={(v) => onChange(v || null)}
    >
      <ComboboxAnchor>
        <ComboboxInput
          id={field.name}
          placeholder={field.placeholder || "Search..."}
          disabled={disabled}
        />
        {!field.required && value && (
          <ComboboxCancel />
        )}
        <ComboboxTrigger disabled={disabled} />
      </ComboboxAnchor>
      <ComboboxContent>
        <ComboboxEmpty>No results found</ComboboxEmpty>
        {options.map((option) => (
          <ComboboxItem key={option.value} value={option.value}>
            <ComboboxItemText>{option.label}</ComboboxItemText>
            <ComboboxItemIndicator />
          </ComboboxItem>
        ))}
      </ComboboxContent>
    </Combobox>
  );
}
```

**IMPORTANT:** The code above is a starting template. You MUST read the actual installed `combobox.tsx` to verify:
1. The exact component names and props match what was installed
2. The `value`/`onValueChange` contract (does it accept `""` for empty or `undefined`?)
3. Whether `ComboboxCancel` exists for clearing selection, or if there's a different pattern
4. Whether `ComboboxContent` needs a portal or is inline

Adjust the implementation to match the actual installed component API.
