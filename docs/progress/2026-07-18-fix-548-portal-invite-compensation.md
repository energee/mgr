- **2026-07-18 (portal invite compensation ordering).** Fixed #548: `compensateExistingPortalUser` in the customer invite route no longer reverts the `user_profiles` row when the preceding `customer_portal_users` delete failed — a partial compensation could otherwise leave a dangling portal-user row referencing a reverted non-customer profile, silently. The profile revert is now gated on the link removal succeeding, and every cleanup failure names the leftover rows (table + ids) in the raised error so operators can repair them.
