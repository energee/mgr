- **2026-07-13 (Dashboard lazy-chart hydration mismatch; branch `sentry-fix/SENTRY-7477285440`, Sentry MGR-6).** `/dashboard` kept generating new hydration-mismatch events (last seen 2026-07-11) even though PR #308 had already fixed the originally-reported cause (ChatLayout's `ChatPanel` using `next/dynamic({ ssr: false })`, merged 2026-07-05) — the fix was already present in the release the last event was tagged with. Root cause of the recurrence: `TrendChartLazy` and `BatchActivityHeatmapLazy` (`src/components/dashboard/`) used the same `next/dynamic({ ssr: false })` pattern, and are rendered inside `ProductionTrends`/`SalesTrends`, which sit inside a `<Suspense>` boundary that itself genuinely suspends (`usePeriod()` → `useSearchParams()`). Nesting a `dynamic(ssr:false)` client-only-bailout boundary inside another suspending boundary is the same class of bug already fixed for ChatLayout. Fix: converted both wrappers to `React.lazy` + an explicit `<Suspense fallback={<Skeleton/>}>` at each of the 4 call sites (`src/app/(app)/dashboard/page.tsx`, `src/app/(app)/dashboard/sales/page.tsx`), mirroring the established ChatLayout fix — same skeleton fallback content and height as before, so no visual change. `cogs-period-chart-lazy.tsx` and `batch-readings-chart-lazy.tsx` use the identical `next/dynamic(ssr:false)` pattern but aren't nested inside a suspending boundary, so they were left untouched. New regression test `src/components/dashboard/__tests__/dashboard-lazy-hydration.test.ts` (7 assertions) fails against the pre-fix source and passes after. Gates: typecheck, full test suite (2230 tests), and lint all green.
