- **2026-07-24 (vitest TZ pin made effective).** Issue #568: `test.env.TZ` in `vitest.config.ts` was inert under `pool: "threads"` (worker threads share the parent process timezone; assigning `process.env.TZ` inside a worker never re-runs `tzset`), so TZ-sensitive tests ran under the host zone — UTC in CI. Fixed by assigning `process.env.TZ` at config module scope, which runs on the main process before any worker spawns; the timezone is process-global, so threads inherit it. `test.env` retained so a fork/child-process runner still gets the value. Added `src/lib/__tests__/test-timezone.test.ts` as a guard (fails with `TZ=UTC` against the pre-fix config, passes after). `make check` green: 193 files / 2517 tests, build clean.
