- **2026-08-11 (codegraph: a queryable knowledge graph of the repo).** Built `tools/codegraph/` on the structure of Anthropic's knowledge-graph cookbook, but with the division of labour inverted where this repo allows: ~98% of the graph comes from parsers, not a model. Final: **3,962 entities / 8,465 relations**, rebuilt in ~7s offline. `graph.json` is committed so a clean clone can query with no build step, and the `codegraph` skill (`.agents/skills/`, symlinked into `.claude/skills/`) points future sessions at it — Grok and Codex discover it too.
  - **Passes.** AST via the repo's own TypeScript compiler (resolved imports/calls, plus `.from()`/`.rpc()`/`dynamicRpc()` for `reads_from`/`writes_to`/`invokes`, and `entityKeys("table")` for `invalidates`). SQL with `live-catalog.snapshot.txt` authoritative for tables/policies/triggers/functions and migrations supplying edges only. LLM (`gpt-5.3-codex-spark` via `codex exec`, ChatGPT subscription, $0 marginal) restricted to `triggered_by`/`documented_in`/`verifies`.
  - **Restricting a schema does not stop a model emitting the wrong thing — it reroutes.** Given the full predicate set, 233 of 262 LLM edges were call-graph facts wearing `handles` (`syncMalts handles upsertRows`). Dropping those two predicates moved the laundering into `DOC` (which then held functions) and `FEATURE` (modules), and every `triggered_by` came back reversed. Fix was validation in code, not re-prompting: each edge checked against a legal (domain, range) pair, reversed ones flipped, and `DOC`/`FEATURE`/endpoint names checked for real shape. 262 → 92 edges, all correct.
  - **Bugs the checkpoints caught, none visible from reading the code.** Policy/trigger names are unique *per table*, not globally — `current_user_enabled` exists on 107 tables and was silently collapsing 106 nodes into one. `dynamicRpc(client, "fn")` hid 9 database functions from the `.rpc()` detector (`invokes` 14 → 44), including both Square ingest RPCs. The first full LLM run invented `POST /api/webhooks/qbo` and `POST /functions/v1/square-webhook`, and claimed `POST` on a GET-only route.
  - **Entity resolution is rules, not inference** — measured zero within-type name collisions across 3,892 entities, because the parsers mint canonical names by construction. An LLM clusterer here could only invent the over-merge it exists to prevent.
  - **Eval** (`eval.ts` + hand-written `eval/gold.json`, one case per extractor) scores 100% precision and recall on all three cases. Scoping is by provenance — every fact records the file it came from — after two wrong topology-based designs.
  - **Residue.** Views are chain-only (`db_source: "chain"`); `summarize.ts` has profiled 3 of 46 domain hubs.
