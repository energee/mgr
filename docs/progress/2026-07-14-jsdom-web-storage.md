- **2026-07-14 (fix red main: jsdom Web Storage).** `src/hooks/__tests__/use-persisted-page-size.test.tsx` (added by #407) failed all 4 of its tests on `main`, breaking `make check` for everyone. The cause is environmental, not a defect in the hook: under this jsdom setup neither the bare `localStorage` global nor `window.localStorage` exists — Node's own experimental global is `undefined` without `--localstorage-file`, and jsdom supplies no Storage of its own — so any bare `localStorage.getItem(...)`, whether in a test or in the code under test, throws on `undefined`. Added a minimal in-memory `Storage` polyfill to `src/test/setup.ts`, applied only when the global is absent. Suite green: 159 files / 2355 tests.
